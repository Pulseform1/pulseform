# Morrowfield 1.4 — assets, licenses, and data

## Original project work

The Morrowfield name, interface, SVG icons, terrain, procedural materials, water rendering, thumbnails, buildings, plants, animals, people, vehicles, and decorations were created for this project. All 675 catalog miniatures are generated by `dist/models.js`; their thumbnails are rendered locally from the same geometry.

The globe in `dist/planet-view.js` also uses original procedural geometry and colors: raised continent shapes, ocean, atmosphere, clouds, and region markers. Its earthlike geography is an artistic overview, not licensed satellite imagery, a geographic dataset, or a continuously editable model of the real Earth. The eight regions are separate building areas.

No downloaded models, photographs, third-party texture packs, branded characters, audio, or web-font files are bundled. Original project models and source are delivered for the user's hosting, modification, and redistribution, without third-party art royalties or subscriptions.

## Hosting and data behavior

The static game has no analytics, advertising, media CDN, or external asset downloads. It serves its own files and keeps the project library in browser storage, normally IndexedDB. It probes the same-origin session endpoint; a static host without that API uses device-only storage. Export downloads JSON, and import reads the file explicitly chosen by the player.

The hosted edition adds account-aware saving. The Sites gateway provides authenticated identity; the Worker exposes same-origin `/api/session` and `/api/projects` routes and stores projects in R2 under account-scoped keys. Hosted sign-in and cloud project operations require network access. A local cache can retain pending changes, subject to browser storage availability. These services are hosting dependencies, not third-party visual assets.

The current hosted preview is private. The downloadable static build does not require Sites, an account, an API key, or a cloud backend. Deploying that static build elsewhere supplies device saves and import/export; account synchronization requires the separate Worker, storage binding, and a trusted authentication boundary. Hosting providers may maintain their own access logs independently of the game's code.

Catalog preview pictures are rendered from the same original procedural models using the included software renderer. No stock imagery or external image service is used.

The 60-building expansion uses original procedural architectural models, including 20 homes, 20 city buildings, and 20 civic/industrial/landmark structures.

The world expansion modules add 540 original procedural models across nine collections. The thumbnail renderer uses a deterministic, per-image color palette to keep all previews compact. No downloaded model packs or external model-image service is used.
