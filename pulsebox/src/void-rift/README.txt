VOID RIFT — Neon Survival

HOW TO PLAY
Extract this ZIP, then open index.html in a modern web browser.
No installation or build step is needed.

CONTROLS
WASD / arrow keys: Move
Mouse: Aim; hold left click to fire
Space / Shift: Dash
E: Rift Nova when fully charged
Escape / P: Pause
Touch devices: On-screen movement, dash, and Nova controls

Chain kills to increase your score multiplier. Choose an upgrade after each
sector. A Dreadnought appears every five sectors. Enable sound with SOUND OFF.

The game runs locally. Optional Google Fonts require internet; system fonts
are used when offline. Personal-best persistence depends on browser support
for local storage when opening local files.
